# Cakez - Cake Design Agency Website

## 📌 Project Description
Cakez is a beautifully designed cake design agency website built using **HTML and CSS**. The project features a responsive layout that adjusts dynamically to different screen sizes, ensuring an optimal user experience.

## 🚀 Features
- Responsive design with **flexbox** for dynamic image scaling.
- Modern typography using **Google Fonts (Poppins)**.
- Elegant and clean layout with a **creative and professional aesthetic**.
- Smooth image resizing for a visually appealing gallery.
- Fully functional **business card-ready logo** integration.

## 🛠️ Technologies Used
- **HTML5**: Structuring the content.
- **CSS3**: Styling and responsiveness.
- **Google Fonts**: Custom typography.
- **Flexbox**: Responsive layout handling.

## 🎨 Setup and Usage
1. **Clone the repository**:
   ```sh
   git clone https://github.com/your-username/cakez.git
   ```
2. **Navigate to the project directory**:
   ```sh
   cd cakez_project
   ```
3. **Open `index.html` in your browser** to view the website.
